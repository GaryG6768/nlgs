NLGS CENTRAL HANDICAP HISTORY – PATCH

The Supabase database part has already been created. This patch makes the existing
NLGS handicap tracker merge each player's local history with the central history,
so the same handicap history follows the player onto another phone.

IMPORTANT:
- Do NOT delete any existing local handicap history.
- Keep the existing migrateOld() and correctKnownRoundDates() functions.
- The Barnham 2 date correction remains unchanged.

FILE 1: nlgs-handicap-v3.js

A) FIND THIS EXISTING BLOCK:

  function saveRounds(r){
    const d=getAll();
    d[memberKey()]=r;
    saveAll(d);
  }

REPLACE IT WITH:

  function saveRoundsLocal(r){
    const d=getAll();
    d[memberKey()]=r;
    saveAll(d);
  }

  let centralSyncTimer=null;
  let centralSyncRunning=false;
  let centralSyncAgain=false;

  function centralMember(){
    const m=getMember();
    if(!m)return null;
    const id=String(m.id||m.member_id||'').trim();
    const fullName=String(m.full_name||m.name||'').trim();
    if(!id||!fullName)return null;
    return {id,fullName};
  }

  function queueCentralSave(){
    if(centralSyncTimer)clearTimeout(centralSyncTimer);
    centralSyncTimer=setTimeout(()=>{
      centralSyncTimer=null;
      syncCentralHistory();
    },300);
  }

  function saveRounds(r){
    saveRoundsLocal(r);
    queueCentralSave();
  }

  async function syncCentralHistory(){
    const cm=centralMember();
    if(!cm||typeof sb==='undefined'||!sb||typeof sb.rpc!=='function')
      return false;

    if(centralSyncRunning){
      centralSyncAgain=true;
      return false;
    }

    centralSyncRunning=true;
    try{
      const local=getRounds();

      const result=await sb.rpc('nlgs_handicap_sync',{
        p_member_id:cm.id,
        p_full_name:cm.fullName,
        p_rounds:local
      });

      if(result.error){
        console.warn('NLGS central handicap sync failed:',result.error);
        return false;
      }

      const merged=Array.isArray(result.data)?result.data:[];
      saveRoundsLocal(merged);
      render();
      return true;

    }catch(e){
      console.warn('NLGS central handicap sync failed:',e);
      return false;

    }finally{
      centralSyncRunning=false;

      if(centralSyncAgain){
        centralSyncAgain=false;
        queueCentralSave();
      }
    }
  }

WHAT THIS WILL DO

1. A player's existing rounds on their current phone are uploaded to the central
   NLGS database.
2. If they log in on another phone, their central history is merged into that
   phone.
3. New manual rounds are also saved centrally.
4. Competition and Friendly Game rounds continue to sync as before.
5. Existing Barnham 2 date correction is kept.
6. No existing local history is deliberately deleted.
